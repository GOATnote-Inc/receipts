# Security policy

This repository is research software. It is not a medical device and must not be used for clinical decision-making.

## Reporting a vulnerability
Email b@thegoatnote.com with the repository name, a description, and reproduction steps. You will receive an acknowledgement within 5 business days. Please do not open a public issue for security reports.

## Scope
- Code in this repository and its GitHub Actions workflows.
- Out of scope: third-party services referenced in docs, synthetic demo data.

## Supported versions
Only the default branch is supported.
